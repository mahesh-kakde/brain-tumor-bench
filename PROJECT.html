🧠 brain-tumor-bench — project reference

everything you need to know about this project: what it does, what tools it uses, how the data is organized, and how the models work.

1. what is this project?

this project is a reproducible benchmark that fairly compares four deep learning architecture families on the task of classifying brain MRI images into four categories:

classdescription
gliomaa type of tumor that starts in the glial cells of the brain
meningiomaa tumor that forms on the membranes covering the brain and spinal cord
no tumorhealthy brain MRI with no tumor present
pituitarya tumor that forms in the pituitary gland at the base of the brain

why does this matter?

existing studies comparing CNNs and vision transformers for brain tumor classification often use different hyperparameters for each model, making it unclear whether performance differences come from the architecture or the tuning. this project fixes that by training all models under identical conditions.

what makes this project different?

  • strictly controlled comparison — all 4 models use the exact same optimizer, learning rate, scheduler, augmentation, and stopping criteria
  • evaluation beyond accuracy — includes calibration (ECE), explainability (deletion faithfulness, perturbation stability), and efficiency metrics
  • multi-seed reporting — every experiment runs 3 times (seeds: 42, 1337, 2026) to report mean ± std
  • transparent data audit — sha-256 hashing and perceptual duplicate detection between datasets

2. the four models

model 1: resnet-50 cnn baseline

a 50-layer convolutional neural network with skip connections. the "classic" choice for image classification.

propertyvalue
typeconvolutional neural network (CNN)
pretrained onimagenet-1k (1.28 million images, 1000 classes)
parameters~25.6 million
custom headdropout(0.2) → linear(2048, 4)
strengthstrong local feature extraction via convolution kernels
xai methodgrad-cam (target: layer4[-1].conv3)

model 2: efficientnet-b0 lightweight cnn

a compact CNN designed by neural architecture search. achieves similar accuracy to resnet with far fewer parameters — relevant for deployment in resource-constrained hospital settings.

propertyvalue
typecompound-scaled CNN with mobile inverted bottleneck (MBConv)
pretrained onimagenet-1k
parameters~5.3 million
custom headdropout(0.2) → linear(1280, 4)
strengthefficiency — much fewer params with competitive accuracy
xai methodgrad-cam (target: features[-1])

model 3: vit-b/16 vision transformer

a vision transformer that splits the image into 16×16 patches and processes them using self-attention. no convolution at all.

propertyvalue
typepure vision transformer
pretrained onimagenet-1k
parameters~86.6 million
tokenisation224×224 image → 196 patches of 16×16 → 768-dim tokens
custom headdropout(0.2) → linear(768, 4)
strengthglobal attention — can capture long-range spatial dependencies
xai methodattention rollout (multiply attention matrices across 12 layers)

model 4: hybrid cnn-vit hybrid

combines a resnet-50 CNN backbone with a transformer encoder head. the CNN extracts spatial features, and the transformer reasons globally over them.

propertyvalue
typeCNN backbone + transformer head
cnn backboneresnet-50 (pretrained, layers 1-4)
transformer head4-layer, 8-head, dim=512, ffn=2048
custom head[cls] token → dropout(0.2) → linear(512, 4)
strengthcombines CNN's local bias + transformer's global reasoning
xai methodgrad-cam (CNN part) + attention rollout (transformer part)

data flow:

input (224×224×3) → resnet-50 layers 1-4 → feature map (7×7×2048) → flatten to 49 tokens → linear projection (2048 → 512) → add positional embeddings + prepend [cls] token → 4-layer transformer encoder (dim=512, 8 heads) → [cls] output → dropout(0.2) → linear(512, 4) → logits

6. evaluation metrics

classification metrics

metricwhat it measures
accuracyfraction of correctly classified samples
macro f1harmonic mean of precision and recall, averaged across classes (primary metric)
macro precisionmean positive predictive value per class
macro recallmean true positive rate per class (clinical sensitivity)
aurocarea under ROC curve (one-vs-rest, macro-averaged)

calibration metric

metricwhat it measures
ECE (15 bins)expected calibration error — how well predicted confidence matches actual accuracy. lower = better.

explainability metrics

metricwhat it measures
deletion faithfulness (del-auc)progressively delete most salient pixels — bigger accuracy drop = more faithful saliency map
perturbation stability (stab)add small noise (σ=0.02) and compare saliency maps — lower distance = more stable explanations

efficiency metrics

metricwhat it measures
parameters (M)total number of model parameters in millions
flops (G)floating-point operations for one forward pass
inference time (ms)mean time to classify one image on GPU

statistical significance

  • paired t-test / wilcoxon signed-rank between all 6 model pairs for macro f1
  • 3 seeds → limited statistical power — results are indicative, not definitive

9. known limitations

  • figshare overlap: ~706 perceptual near-duplicates exist between kaggle and figshare. external results are sensitivity checks only.
  • 2D slices only: we classify individual 2D MRI slices, not 3D volumetric data.
  • single dataset family: results may not generalise to other MRI datasets.
  • no model-specific tuning: each model may not be at its individual optimum — intentional for fair comparison.
  • imagenet pretraining: results reflect fine-tuning performance, not training from scratch.
  • batch size constraint: fixed batch_size=32 for all models (ViTs sometimes prefer larger batches).
  • limited statistical power: only 3 seeds per model — significance tests are indicative, not definitive.
  • hybrid is not novel: included as a representative architecture, not as a novel contribution.
  • xai method variation: different xai methods for different architectures — cross-architecture comparisons should be interpreted carefully.
